# 微信小程序复审说明

## 建议小程序名称

共享钓场

## 建议小程序简称

共享钓场

## 建议小程序简介

共享钓场提供合作钓场的扫码入场、计时计费、离场结算、钓位预订、钓具租赁、放鱼动态、现场补给和订单服务。

## 复审说明

本次已按审核意见移除用户公开发布与互动功能：

- 原“钓获社区”已改为“我的钓获”，仅登录用户本人可查看自己的称重及活动审核记录。
- 页面不再提供用户发布文字、图片、点赞、评论、回复或访问他人内容的能力。
- 原“拼场约钓”用户组局功能已从小程序页面、入口和开放接口中下线。
- 放鱼动态、活动和赛事内容均由钓场后台统一发布，不是用户生成内容。
- 排行榜只展示系统根据后台确认的称重数据和积分数据自动生成的成绩，不提供用户自定义内容发布。

小程序当前核心功能为合作钓场扫码入场、实时计时计费、离场结算、订单查看、钓位预订、个人钓获记录、放鱼动态、钓具租赁、现场补给和客服咨询，不再提供公开社交或笔记服务。

### 建议粘贴到提审备注

已按上次审核意见完成整改。原钓获社区已改为仅本人可查看的“我的钓获”，用户不能发布文字或图片，不能浏览他人钓获，也没有点赞、评论、回复和分享入口；用户拼场组局功能也已下线。放鱼信息、活动及赛事均由运营后台统一发布。请审核人员从首页“我的钓获”进入核验。

## 提审前检查

- 微信公众平台的小程序名称使用“共享钓场”。
- 微信公众平台的小程序简称使用“共享钓场”或“钓场计时”，不要填写长句。
- 微信公众平台的小程序简介使用上方建议简介，或保持同等含义。
- 上传正式版时首页能正常展示扫码入场、计时计费、离场结算和“我的钓获”等钓场服务内容。
- “我的钓获”页面必须清楚显示“仅自己可见”，且不能出现发布、点赞、评论、回复和查看他人内容的入口。
- 小程序中不能出现“钓获社区”“发帖”“晒单”“拼场约钓”等公开社交文案和入口。
- 服务类目应选择与钓鱼场地、休闲娱乐、场地预约或生活服务相匹配的类目。
